# ShelfLife

ShelfLife is a React web app that helps users keep track of books, courses, TV shows, games, and personal projects in one place.

## Features

1. Add items to your shelf
2. Organize different categories
3.Track progress
4. Firebase Authentication

## Tech Stack

 React
 Firebase Authentication
 Cloud Firestore
 CSS

## What I Learned

ShelfLife was my first larger React project. While building it, I learned:

 React components
 State management
 Firebase Authentication
 Firestore basics
 Organizing a larger project structure
