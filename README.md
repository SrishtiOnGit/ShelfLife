# ShelfLife

ShelfLife is a React web app that helps users keep track of books, courses, TV shows, games, and personal projects in one place.

## Features

1. Add items to your shelf
2. Organize different categories
3.Track progress
4. Firebase Authentication

## Tech Stack

 1.React
 2.Firebase Authentication
 3.Cloud Firestore
 4.CSS

## What I Learned

ShelfLife was my first larger React project. I learned:

 1.React components
 2.State management
 3.Firebase Authentication
 4.Firestore basics
