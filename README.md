## ShelfLife
ShelfLife is a clean, minimalist web app built to track everything you're currently consuming or working on—from books and online courses to dev projects, games, and TV series.

Instead of jumping between spreadsheets, notes apps, or dedicated tracking sites, ShelfLife keeps your media shelves and progress items organized under a single, beautiful dashboard.

## Tech Stack & UI Theme
Frontend: React

Database & Auth: Google Firebase / Cloud Firestore

Styling: Vanilla CSS3 with premium slate and emerald palette details:

Background: #0F172A
